# 05 — Regras de Negócio

Somente regras já conhecidas. Nenhuma regra administrativa da igreja deve ser inventada; o que não foi informado fica como PENDENTE DE DEFINIÇÃO e vai para `11-PENDENCIAS.md`.

## Estrutura administrativa
| ID | Regra |
|---|---|
| RN-01 | A hierarquia é Região → Área → Polo → Igreja. |
| RN-02 | Toda Igreja pertence a exatamente um Polo; todo Polo a uma Área; toda Área a uma Região. |

## Obras
| ID | Regra |
|---|---|
| RN-03 | Os tipos de obra são: reforma, ampliação, construção e manutenção. |
| RN-04 | Toda obra tem uma prioridade: Emergencial, P1, P2 ou P3. |
| RN-05 | Toda obra nasce de uma solicitação feita por uma Igreja. |
| RN-06 | A execução da obra é acompanhada em cinco fases. Nomes das fases: PENDENTE DE DEFINIÇÃO. |

## Aprovações
| ID | Regra |
|---|---|
| RN-07 | Solicitações passam por aprovações hierárquicas antes da análise do Presbitério. Níveis e ordem: PENDENTE DE DEFINIÇÃO. |
| RN-08 | O Presbitério analisa e trata orçamentos. Critérios: PENDENTE DE DEFINIÇÃO. |

## Rastreabilidade e auditoria
| ID | Regra |
|---|---|
| RN-09 | Toda ação relevante registra usuário, data/hora e conteúdo alterado. |
| RN-10 | Registros relevantes não são excluídos fisicamente; devem manter rastro (forma exata: PENDENTE DE DEFINIÇÃO). |

## Acesso
| ID | Regra |
|---|---|
| RN-11 | Nenhuma funcionalidade é acessível sem autenticação. |
